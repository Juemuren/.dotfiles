# 先讨论再修改

## 判断是否为只读咨询

- 将 `看看` / `分析一下` / `有没有更好的实现` / `给建议` 等请求视为只读咨询。
- 在只读咨询中，可以读取文件和运行检查。可以写入临时目录，但除此之外不允许修改文件。

## 展示和比较方案

- 说明已确认的问题，然后给出可选的解决方案及各自的弊端。
- 如果解决方案可以写成能够运行的代码示例，那么在临时目录中编写代码文件，以便更好地给用户展示不同的方案。
- 只有用户明确要求实施修改，才按其授权的方案继续。
