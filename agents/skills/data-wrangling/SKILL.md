## 识别数据格式

数据格式分为文本格式和二进制格式。

数据格式通常由后缀表示。当后缀不可信时，可以用 `file` 辅助识别文件类型和编码。

```sh
file data.ext
```

对于文本格式，还需要结合文件内容和解析器进行确认。

比如对于 JSON，可以用 `jq` 检查解析是否成功并查看顶层类型。

```sh
jq 'type' data.json
```

## 检查数据规模

在处理前先通过文件元数据查看字节数量，然后可以进一步统计行数、列数等信息。

比如可以先用 `stat` 查看字节数量。

```sh
stat -c %s data.json
```

然后可以使用 `wc` 统计行数、词数和字节数。

```sh
wc data.json
```

对于 CSV，还可以使用 `cat` 和 `head` 查看第一行以确认列数。

```sh
cat data.csv | head -n 1
```

对于大文件，优先选择支持流式处理、谓词下推或无需一次性加载全部数据的工具。

## 判断数据模型

数据模型主要包括表型数据、树型数据、图型数据。

数据模型并不严格对应于文件格式，尤其是 JSON / YAML / XML。

数据模型可以根据顶层类型、重复元素的结构一致性、嵌套深度以及对象之间的引用关系来判断。

- 当数据由字段结构相近的重复记录组成时，可以认为数据偏表状。
- 当数据中存在复杂的嵌套或递归包含时，可以认为数据偏树状。
- 当数据中存在互相引用或网络结构时，可以认为数据偏图状。

对于小型 JSON 文件，可以使用 `jq` 进行路径遍历。

```sh
jq -c 'paths' data.json
```

对于大型 JSON 文件，优先通过 schema、元数据或少量记录判断数据模型。

```sh
jq --argjson sample_size 5 --argjson key_limit 10 \
  -f '<skill-dir>/scripts/json-sample.jq' data.json
```

使用 [json-sample.jq](scripts/json-sample.jq) 时：

- 将 `<skill-dir>` 替换为本 skill 的实际目录
- 参数 `sample_size` 表示对 array 的 value 进行抽样的数量，默认为 3
- 参数 `key_limit` 表示对 object 的 key 进行枚举的数量，默认为 30

对于较小的 YAML / XML，可以先用 `yq` 转为 JSON，再判断数据模型。

```sh
# YAML
yq -p=yaml -o=json '.' data.yaml | jq -c 'paths'
# XML
yq -p=xml -o=json '.' data.xml | jq -c 'paths'
```

## 明确操作类型

根据任务目标，明确操作的类型和注意事项：

- 查询：对数据进行查询或统计，包括筛选、聚合等具体操作。需要注意字段名称、筛选条件、缺失值处理。
- 清洗：去除异常或重复数据。需要注意类型转换、默认值、异常记录处理、去重键和保留规则。
- 转换：转换文件格式。需要注意输入格式和输出格式之间的差异、应该保留的格式特性。
- 合并：把多份数据合为一份数据。需要注意字段对齐、关联键、预期的一对一或一对多关系、未匹配记录处理。
- 重塑：不改变数据含义的情况下修改数据结构。需要注意字段类型、嵌套数组展开方式。

## 选择处理工具

综合格式、规模、模型和操作选择工具，并沿用用户指定的工具或项目已有依赖。

优先选择可以直接完成任务的工具，需要时也可以组合工具。

### jq

- jq 用于树状 JSON 的查询和修改。
- 如果树状 JSON 中嵌套了表状数据，可以用 jq 提取后给 duckdb、mlr 等工具处理。

### yq

- yq 用于在树状数据之间转换格式，包括 YAML / TOML / XML / JSON 等格式。
- 如果不需要保留原格式的特性，且需要 jq 的复杂过滤能力，可以转为 JSON 后让 jq 处理。

### duckdb

- duckdb 用于处理表状数据，包括 CSV / TSV / JSONL / Parquet / SQLite 等。
- 需要多表关联、窗口计算、复杂聚合和大规模分析时，使用 duckdb。

### mlr

- mlr 用于在表状数据之间转换格式，包括 CSV / TSV / JSONL 等。
- 简单的筛选、排序、聚合、清洗、转换等操作可以使用 mlr；涉及复杂 SQL 关系运算时应优先使用 duckdb。

### python

- python 用于需要复杂逻辑的数据处理。
- 适合自定义解析、复杂业务规则或现有命令行工具难以表达的处理。优先使用标准库或项目已有库。
- 当现成工具可以简单地完成任务时，就不要用 python 重复实现已有的功能。

### awk

- awk 用于处理无固定结构的纯文本数据，比如日志、命令输出等。
- 当数据没有专门的解析器，且无法按行和简单分隔符进行解析时，请使用 python。
- 当数据已经是一种标准的结构化格式时，请使用专门的解析器，而不是用 awk。
