# 收集工具问题

## 判断任务能否继续

- 如果因开发环境存在问题而无法继续任务，请不要擅自做出决策，而是记录问题，给出修复建议，并等待后续指令。
- 如果任务已经成功完成，或者能够使用别的方法继续，请仍然要记录输出中的噪声。

## 记录问题

- 将问题以 Markdown 文件格式保存到 `<project-root>/tmp` 目录下，文件名要能够反映问题的概要。
- 在 Front Matter 中记录时间戳、工作目录和命令来源。
- 在正文中记录问题日志、问题分析和修复建议。

具体内容和格式请参考 [global-gitignore-permission](assets/global-gitignore-permission.md)。
